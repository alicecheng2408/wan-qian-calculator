# 千萬計算機

手機優先的繁體中文 PWA 計算機，支援可編輯算式、精確十進位運算，以及「千／萬」快捷輸入與口語輸入建議。

## 本機執行

```bash
pnpm install
pnpm dev
```

瀏覽器開啟終端顯示的網址。手機測試時，需讓手機與電腦位於同一網路，並以 `pnpm dev --host` 啟動。

## 驗證與建置

```bash
pnpm test
pnpm build
pnpm preview
```

正式發布檔案會產生於 `dist/`。PWA 的 Service Worker 僅在正式建置模式註冊。

## 輸入規則

- `8.8萬` 等於 `88,000`，`2.5千` 等於 `2,500`。
- `(2+3)萬` 等於 `50,000`。
- `3萬5` 與 `3萬5千` 會顯示建議，確認後標準化為 `3.5萬`。
- 模糊單位、除以零及未完成算式不會產生答案。
